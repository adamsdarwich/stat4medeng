NoteKey Takeaways
  • Standard errors and confidence intervals describe the precision of parameter estimates. When a standard error is difficult to obtain directly, we can consider the delta method or resampling.
  • The jackknife repeatedly leaves out one observation and recalculates the statistic. For a given dataset and statistic, it is a deterministic procedure.
  • The bootstrap repeatedly samples from the observed data with replacement. The resulting distribution of estimates can be used to obtain standard errors and confidence intervals.
  • Permutation tests generate a reference distribution under the null hypothesis by rearranging the data in ways allowed by the study design. They require exchangeability.
  • The type of outcome, the study design and the question we want to answer should guide the choice of statistical method.

L7 Resampling and Course Summary

Resampling Statistics

This final lecture gives a brief introduction to resampling statistics. When would we make use of these methods?

When reporting an estimate of a parameter, which we can call \(\hat\theta\), we often also report its standard error or confidence interval as a measure of the precision of that estimate. We can approximate a confidence interval using the standard error. Sometimes, however, the standard error is difficult to obtain, or the estimate has a less common sampling distribution. We then need another way to work out its uncertainty.

Confidence Intervals and the Delta Method

Using a normal approximation, a 95% confidence interval takes the form:

\[ \hat\theta\pm1.96\,\mathrm{SE}(\hat\theta). \]

More generally, a \(100(1-\alpha)\%\) confidence interval is:

\[ \hat\theta\pm z_{1-\alpha/2}\,\mathrm{SE}(\hat\theta), \]

where \(z_{1-\alpha/2}\) is the corresponding standard normal quantile.

What can we do when the standard error is not known? A traditional solution is the delta method. This uses a Taylor expansion to approximate the standard error of a function of parameter estimates. We use the estimates together with their covariance matrix to obtain an approximate standard error for the transformed quantity.

The msm package, which also deals with Markov modelling, includes the function deltamethod() for this purpose.

Resampling Methods

An alternative is to use resampling methods. These provide ways of obtaining or approximating sampling distributions of statistics, from which we can estimate standard errors and confidence intervals or carry out hypothesis tests.

We will briefly consider three types:

  • Jackknife.
  • Bootstrap.
  • Permutation tests, which we encountered in the first lecture series.

The Jackknife

The jackknife is one of the early approaches to resampling. It uses a leave-one-out approach, similar to leave-one-out validation in machine learning.

For each resample, we leave out one observation and calculate the statistic using the remaining observations. We repeat this for every observation in the dataset. For a dataset of size \(n\), this gives \(n\) leave-one-out estimates.

This is a deterministic process: for the same data and statistic, we obtain the same results each time. We can use the leave-one-out estimates to estimate the standard error and construct a confidence interval for the statistic of interest.

In R, we can use the bootstrap package. The following follows the lecture example, using a simulated normally distributed dataset and the mean as the statistic:

set.seed(7)
n <- 100
population_mean <- 10
population_sd <- 2

dat <- rnorm(n, mean = population_mean, sd = population_sd)
theta <- function(dat) mean(dat)

x_jk <- bootstrap::jackknife(dat, theta)
x_jk$jack.se
[1] 0.1917614

The simulation values are illustrative. The jackknife procedure itself is deterministic once dat has been generated.

Using the jackknife standard error, we can calculate an approximate normal-based confidence interval:

theta_hat <- theta(dat)
theta_hat + c(-1, 1) * 1.96 * x_jk$jack.se
[1]  9.901541 10.653246

Bootstrapping

A more flexible approach is bootstrapping. It is more computationally demanding, although this is usually less of an issue with modern computing. It can be adapted to many types of estimation problem.

The basic principle is to treat the observed dataset as an empirical population and repeatedly sample from it with replacement. Sampling with replacement means that an observation can appear more than once in a resampled dataset, while some observations may not appear at all.

For each resampled dataset, we calculate the statistic of interest. This gives a bootstrap distribution of the estimates, which we can use to calculate a standard error or confidence interval.

Unlike the jackknife, the bootstrap involves random sampling, so results vary slightly between runs. We usually use many resamples, for example 1,000 to 10,000, to make the results more stable. Setting a random seed allows us to reproduce a particular run.

Using the same data and statistic as above:

set.seed(7)
nboot <- 10000
boot1 <- bootstrap::bootstrap(dat, nboot, theta)

# Bootstrap standard error.
sd(boot1$thetastar)
[1] 0.1895927
# Percentile-based 95% confidence interval.
ci95 <- quantile(boot1$thetastar, c(0.025, 0.975))
ci95
     2.5%     97.5% 
 9.904601 10.650016

The thetastar component contains the statistic calculated for each bootstrap resample. Here, each value is the mean of one resampled dataset. The main point is that we can use the same principle for many other statistics.

Non-Parametric Bootstrapping: The Procedure

We can summarise the procedure as follows:

  1. Start with a dataset \(D\) containing \(n\) observations.
  2. Compute the estimate \(\hat\theta\) of the parameter \(\theta\) from \(D\).
  3. Make a bootstrap dataset \(B_1\) of size \(n\) by resampling \(D\) with replacement.
  4. Repeat this to produce \(b\) bootstrap datasets, \(B_1,B_2,\ldots,B_b\).
  5. Calculate the estimate \(\hat\theta_i^*\) for each bootstrap dataset \(B_i\).
  6. Use the resulting bootstrap distribution to estimate uncertainty.

For a percentile-based 95% confidence interval, we take the 2.5th and 97.5th percentiles of the bootstrap estimates. In R, this is the quantile() calculation above.

Packages for bootstrap calculations include bootstrap, boot and bcaboot.

Using Bootstrapping

Bootstrapping can help us obtain confidence intervals for common statistics with unusual sampling distributions, or for functions of regression coefficients.

The slides give an example from radiological imaging. A contrast-to-noise ratio (CNR) is described by a parabola:

\[ y=b_0+b_1x+b_2x^2. \]

For a downward-opening parabola, the maximum occurs at:

\[ x_{\max}=-\frac{b_1}{2b_2}. \]

We may be interested in a confidence interval for the location of this maximum. The slide example obtains this using bcaboot. The delta method provides an alternative way to approximate the uncertainty of this function of the regression coefficients.

Permutation Tests

Another type of resampling method is the permutation test, which we discussed in the first lecture series.

The idea is to assume that the null hypothesis is true and rearrange the observed data to establish a reference distribution for a test statistic. An exact procedure considers all permitted rearrangements. This can be computationally demanding, particularly for large datasets.

Permutation tests do not require normally distributed observations, but they do require exchangeability under the null hypothesis. This means that the rearrangements must be valid for the study design. For example, randomisation in an experiment can justify exchanging treatment labels.

One special case is Fisher’s exact test, which we can use for categorical data represented in a contingency table. For a reminder of the underlying principle, see the first lecture series on non-parametric statistical tests.

The slides also mention exact logistic regression as an option for small datasets where the usual large-sample approximations may be unsuitable.

Permutation Tests in R

Permutation methods can provide an alternative to linear models and standard non-parametric tests when the distribution is uncertain. With the lmPerm package, lmp() uses a formula in much the same way as lm():

# y and x are the outcome and explanatory variable from the study.
lmPerm::lmp(y ~ x)

Exact computation works well for small datasets. The important consideration is whether the observations are exchangeable in the way required by the analysis.
